# 生产线装配工 · viral-producer-bootstrap

轻量专家包（约 48 KB）。作用是**把整套「开源爆款短视频生产线」装到任意一台电脑上，然后直接跑起来**。

## 它解决的痛点

换电脑时不用手动复制文件、不用装 git、不用配 SSH key。导入这个专家包，说一句话，
它自己从 GitHub 下载全套 → 安装 → 验收 → 执行产线。

## 用法

导入后在 WorkBuddy 里说：

- 「把爆款生产线装到这台电脑」
- 「装好生产线，然后抓最近 7 天的开源项目跑一遍」
- 「检查这台电脑的生产线装得全不全」

## 技术要点

| 项 | 说明 |
|---|---|
| 下载方式 | `codeload.github.com` 直连 zip，纯 HTTP，**不依赖 git** |
| 认证 | 公开仓库**免认证**；私有仓库才需 `--token` |
| 跨平台 | macOS / Linux / Windows，只用 Python 标准库 |
| 安装位置 | 默认用户主目录下同名文件夹，可用 `--dir` 覆盖 |
| 幂等 | 可重复执行；目录已存在则跳过下载，加 `--force` 强制重装 |

## 与「爆导」专家包的分工

| | 装配工（本包） | 爆导 |
|---|---|---|
| 体积 | 48 KB | 520 KB |
| 内容 | 只有 1 个安装技能 | 自带全部 5 个技能 |
| 版本 | 永远拉最新 | 打包时的快照 |
| 适用 | 换机、升级、改坏了重载 | 断网、图省事、离线导入 |

日常用装配工拉最新版；网络不通时导入爆导的 zip。

## 配置

`skills/viral-producer-sync/config.json`：

```json
{"owner": "TianLeung", "repo": "github-viral-producer", "branch": "main"}
```

改仓库就改这三个字段。私有仓库把 `public` 设为 false，运行时传 `--token`。
