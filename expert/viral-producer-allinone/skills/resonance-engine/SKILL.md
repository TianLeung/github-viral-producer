# 核心共鸣洗稿引擎（Resonance Engine）

## 铁律

**收到 GitHub 项目说明后，禁止直接翻译技术特性。写口播前，必须先在后台完成三步洗稿过滤。**

## 第一步前置：本地化障碍检测（踩过坑，必做）

锚定人群前，先检查项目有没有这三类障碍。**命中任意一条 → 直接跳到下方 C 反常识流，不要按 A 卖工具本身**：

| 障碍 | 检查点 | 命中后的转向 |
|---|---|---|
| **语言/区域** | 界面、文案、内置数据是不是中文？菜品/地名/币种是不是国内的？ | 卖「抄壳改数据」，不卖「直接用」 |
| **运行门槛** | 需不需要 Node/Python/Docker/特定硬件？小白几步能跑起来？ | 卖「思路与可改的源码」，并**如实讲清门槛** |
| **数据可达性** | 内置数据集对受众有没有意义？（如越南菜谱、国外地图数据） | 卖「换成你自己的数据」这个动作 |

> 实测案例：越南语午饭转盘 truanayangi（598⭐）——常规洗稿"用它决定午饭"会被评论区
> "越南菜我吃啥？"打脸。正确解法是切 C 维度：不卖工具，卖「把那几行菜名换成你楼下那六家」。

## 第一步：最大公约数人群锚定

阅读完 GitHub 简介后，先回答这个问题（写进提纯单）：

> 这个工具如果不仅限于程序员用，**普通小白 / 自媒体 / 打工人**能拿它干嘛？

- 示例：「一个网页自动化抓取工具，支持 Python 脚本和正则」
  → 人群锚定：「每天复制粘贴数据的运营」「写论文找资料的学生」
- **砍掉受众窄的功能**：只保留泛人群用得上的能力，程序员向功能降级为一句带过或直接删。
- **README 表述陷阱**：`no login, no backend required` 这类话，务必确认是**哪个版本**成立
  （实测：truanayangi 官网有 API 和登录 cookie，"无后端"仅本地社区版成立）。说错就是硬伤。

## 第二步：痛点反推与极端化场景

- 只挑 **2-3 个**最能解决大众麻烦的核心功能。
- **忽略 README 里 80% 的技术细节**（安装环境、Docker 部署、模型架构等），一个都不许进口播。
- 每个保留的功能，用「**以前你有多惨 VS 现在有多爽**」的逻辑重新包装。
- 示例：不写「采用了最新的边缘检测算法」，
  → 写「以前用 PS 扣头发丝扣到眼瞎，现在连背景里的叶子都能一秒钟给你剥干净」。

## 第三步：说人话渲染

- **绝对禁止**书面说明文体。
- 情绪词库（.pages 原文自带 + 补充）：`直接抄作业`、`杀疯了`、`直接掀桌子`、`别再去花冤枉钱了`、
  `这玩意能随便魔改`、`懂得都懂`、`白嫖`、`省下一整天无效加班`。
- 再叠加《短视频爆款文案改写专家》三板斧（缓存 md：`短视频爆款文案改写专家.md`）：
  1. **描述法**：用动作细节替代形容词——不写「风大」，写「大衣帽子扣头上，头发被吹飞」
  2. **类比法**：不写「减了25斤」，写「减了一桶饮水机的水」
  3. **对比法**：兜里只剩4块钱 vs 乞丐碗里有10块钱
- **去形容词化**：发现形容词 → 换成「名词+动词」的动作细节。
- **力量动词**：削、拍、怼、踹、砸 > 打、按、放。
- 字数约束：单条口播正文 **200-300 字**；禁用「虽然、但是、因此」等长逻辑连接词。

## 逻辑平移（选题内核，来自《知识博主选题"逻辑平移"公式》）

原版「认知劫持 5 步法」的开源工具适配版：

| 步骤 | 原版（卖课） | 开源工具适配版 |
|---|---|---|
| ① 认知切入 | 纯观点，30 秒 0 广告 | 前 5 秒纯讲大众痛点，**不出现项目名** |
| ② 逻辑爆破 | 摧毁旧认知 | 「你还在用付费/人肉的方式干这件事？」 |
| ③ 痛点内化 | 映射个人惨状 | 具体场景化：加班到 11 点还在复制粘贴 |
| ④ 降维救赎 | 产品=外挂 | 工具登场：「我把作业直接放评论区了」 |
| ⑤ 筛选转化 | 高姿态筛选 | **软化版**：提问式引导（"你第一个想拿它 automate 什么？评论区见"），不用"想白嫖的划走"这类高姿态话术 |

三个选题维度（出 3 条不同角度的选题）：
- **A 通用工具流**：人人都用得上的效率外挂
- **B 时代红利流**：AI 浪潮里的最新杠杆，普通人现在上车正好
- **C 反常识流**：这个付费功能，有个开源的免费平替

## 标题与钩子生成（Step 5）

- **标题**：从《30个标题提示词》的 30 种技巧中选 **3-5 个**最契合当前情绪的，每个标题 ≤ 20 字，
  每个后面跟 3-4 个相关标签。封面标题从中选 1 个。
- **钩子**：从《40个钩子提示词》的 40 类中选 **3 个**候选，写成前 5 秒口播（每条 ≤ 45 字），
  要求反差感或直击痛点。生成前先内部完成 13 项用户洞察（信息补充那套），不必展示。
- 素材库原文（缓存）：`.workbuddy/cache/prompts-md/30个标题提示词.md`、`40个钩子提示词.md`

## 输出格式：《选题提纯单》

```
一、人群锚定：xxx（一句话）
二、痛点场景（2-3 个，惨VS爽结构）：
   1. 以前…… 现在……
   2. ……
三、选题三维度：A 通用工具流 / B 时代红利流 / C 反常识流（各一句话定位）
四、标题 3-5 个（带标签），标注推荐封面标题
五、钩子 3 条（≤45字/条），标注推荐钩子
六、口播正文（200-300 字，已过三步洗稿）
```

## 自检（输出前提纯单前默念 3 行）

1. 有没有未翻译的技术词混进人群锚定和痛点场景？有 → 回炉
2. 痛点是不是标准的「以前多惨 VS 现在多爽」结构？不是 → 重写
3. 口播正文有没有书面腔 / 超出 300 字 / 形容词堆砌？有 → 用三板斧再过一遍
