## 一、视频名片

**项目名**：gongwen-gbt9704-skill（`mizzlelover/gongwen-gbt9704-skill`）

**一句话定位**：给体制内、国企、事业单位写材料的人，一个按 GB/T 9704-2012 国标一键生成可编辑 DOCX 的公文排版外挂——不用再为了页边距和字号，被领导打回第三遍。

**视频标题（3 选 1）**
1. 排了三小时的公文，它一条命令搞定（16 字）← **推荐封面**
2. 领导说"格式不对"？国标它替你背了（16 字）
3. 公文差几毫米就卡住，这个开源工具专治（17 字）

**封面建议**：左右分屏硬对比。左半屏是排版崩坏的原稿（标题字号不一、缩进乱、页边距肉眼可见歪），盖**红字**「改了三遍」；右半屏是标准红头公文成品，盖**黄字**「一次成型」；中间一道黄色撕裂分割线。顶部压黄字大字：**「格式不对，重排。」**

**目标人群**：体制内/事业单位/国企文秘与办公室岗 ｜ 刚上岸的新人（第一份活就是排版）｜ 行政 HR ｜ 需要交正式报告的方案岗

**关键数据**：⭐ 589（创建 7 天）｜ MIT 协议 ｜ GB/T 9704-2012 现行国标（2025-05-30 复审继续有效）｜ 可装进 Codex / Claude Code / Kimi / Trae / WorkBuddy 等 9+ 个客户端

## 二、选题提纯单（洗稿过程留痕）

### 第一步前置：本地化障碍检测
- 语言/区域：**无**（原生中文，对标国内现行国标）✅
- 运行门槛：**命中** —— 需 Node.js + 一个 AI 客户端（Claude Code / Kimi / WorkBuddy / Trae 等）⚠️
- 数据可达性：无 ✅

→ 走 **A 通用工具流**为主。运行门槛必须在第 8 镜如实说清，不许含糊。

### 第一步：最大公约数人群锚定

**锚定**：体制内 / 事业单位 / 国企里，天天跟正式材料打交道的人。他们的痛不是写不出来，是**写完交不出去**。

**被砍掉的程序员向内容**（一个都不进口播）：
`.mjs` 脚本名、`--letterhead-reserve-mm 72`、`--require-standard-fonts`、`--joint-org`、`--attachment-detached`、`--profile formal`、18 份 DOCX / 37 个 PNG 视觉审计、PDF 字形坐标量测、Word/WPS 大纲级别、版记线粗 0.35mm / 0.25mm、信函/命令/纪要专用分支。

### 第二步：痛点反推（惨 VS 爽）

| | 以前多惨 | 现在多爽 |
|---|---|---|
| 字号版心 | 标题层级手动调，段前段后缩进一处处对，改一遍半小时 | 版心、字体、四级标题直接写进 Word 样式 |
| 红头 | 红头文号间距全靠眼估，打印出来差几毫米被退回 | 预印红头纸套打，首页按毫米留白，不重绘红线 |
| 交稿前 | 交出去才发现"这不是公文格式"，连带内容一起被否 | 生成完有校验器先自查，缺字体提前报警 |

### 第三步：说人话渲染
三板斧落地：
- **描述法**：不说"格式不规范"，说"排到第三遍才发现，差的是几毫米"
- **对比法**：左屏狗屎原稿 / 右屏国标成稿，同屏硬怼
- **去形容词化**：不说"大幅提升效率"，说"页边距真不用再手动调"

**必须打码 / 规避**
- ⚠️ **绝不演示真实公文**：单位名、文号、正文全部用"示例单位文件""示例发〔2026〕1 号"这类占位内容
- ⚠️ 不出现任何真实红头、真实印章、真实签发人
- ⚠️ 不出现任何机关内部文件的真实片段

**口播雷区（照着念必翻车）**
